# Material Dynamics Laboratory replica

A standalone static replica of https://www.sunitamishra.com/ with all six main pages, local images and fonts, a seven-panel slideshow, and material-testing video playback. External scholarly links and YouTube embeds retain their original destinations.

Run `npm run build`, then `npm run dev`. Open http://127.0.0.1:4173.

Page markup is in `src/pages`, shared interactions in `src/app.js`, and shared adjustments in `src/replica.css`. The imported original desktop layout is preserved, including its fixed-width behavior on narrow screens.

The original laboratory copyright notice and attribution are preserved. Source content was captured on 12 October 2026. The visit counter records visits in this browser independently of the original website; videos remain subject to their providers' availability and embedding permissions.
